# ポスターQ＆A
- なぜ有理関数？
	- まず、多項式を使いたいというのがあります。有理関数は多項式を多項式で割ったものですが、多項式だけで構成されていると、四則演算のみで計算できるため、高速に計算できます。
	- 単なる多項式ではなく、分母にも多項式があるおかげで、モデルの表現能力が多項式よりも上がるメリットがあります。経験的な事実として、有理関数の方が、(同じ次数に対して)より高精度な近似を得られることがわかっています。
- 変数変換はどうやって見つけた？
	- 基本的に、逆CDF $F_{X}^{-1}(u)$や$F_{Y|X=x}^{-1}(v)$の形状と似た形状の関数を当てはめています。基本的には目視による判断です。
- なぜSobol'列を使うのか？
	- 今回は、準モンテカルロ法への応用ということを考えておりまして、真の期待値と準モンテカルロ平均値の誤差が、ポスター(6)における「Koksma-Hlawkaの不等式」の収束オーダーを満たす(または上回る)ものとして「low-discrepancy列」と呼ばれる乱数列のクラスを考えています。low-discrapancy列という数列の中で特に標準的ものでSobol'列というのがあり、それを使っています。
- どういう分野への応用を考えているか？
	- 特に金融分野のシミュレーションを考えています。というのも、金融のリスク管理やオプションプライシングでは必要な乱数の数$M$の値が非常に大きく、収束オーダーの違いが顕著に表れるので、通常のモンテカルロを、より収束オーダーが良い準モンテカルロ法に置き換えることに価値があるのではないかと、考えました。それが研究の動機になっています。
- **$u,v \in \lbrack\epsilon, 1 - \epsilon\rbrack$としていることの説明**
	- 特にSobol列によるQMCの場合、列の生成規則から、試行回数が$N$なら、左端の点の座標は約$\frac{1}{2N}$、右端の点の座標は約$1- \frac{1}{2N}$になる
	- $N = 10^7$の場合、Sobol列の左端の点の座標は約$5.0 \times 10^{-8}$ となるので、$\epsilon = 10^{-8}$ に取れば、準乱数は区間$[\epsilon, 1 - \epsilon]$の外にはみ出ることはない
	- つまり、$N$の大きさによって適切な$\epsilon$ を取って$[\epsilon, 1 - \epsilon]$の範囲で近似できていれば十分である

- ニューラルネットワーク(NN)を使うのはどうなのか？
	- 今回のケースの関数近似では、NNは弱いのです。
		- NNは原理上、急峻な変化を持つ関数の近似を苦手としています。今回近似したい逆CDFは急峻な変化を持つ場合が多く、NNは近似モデルとして適していません。
		- 実際にいくつかの急峻な変化を持つ関数に対して、同じ標本データを使って有理関数補間法による近似とNNによる近似を比較したところ、有理関数に対してNNは、近似精度が目標に遠く達しない結果が確かめられました。
- Brent法とは？
	- 求根アルゴリズムの一種で、Newton法の改良版と考えて頂いて問題ないです。二分法や割線法などのアイデアを組み合わせていて、Newton法よりも収束が失敗しにくくなる工夫がなされています。
- 補間データの生成に時間はどれくらいかかるのか？
	- 関数依存ですが、設定した補間点の個数分だけ数値積分と求根アルゴリズムを走らせる必要があります。
- 近似モデルを作るときに求根アルゴリズムを走らせるなら求根アルゴリズムでいいのでは？
	- 一度限りの乱数生成でよくて、かつ一度に生成したい乱数の個数が比較的少ない場合ならば、その通りです。
	- しかし、金融シミュレーションなど1千万、1億個の乱数を生成したい、それを何度も使いたい
